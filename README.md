# Sales Data Analysis with Python & Pandas

# Overview
This project analyzes a small sales dataset using Python and Pandas

# Analysis
The project includes:
* Data filtering and soring
* Sales and profit analysis
* Grouping data by product and region
* Basic data visualization
* Key findings from the dataset

# Tools
* Python
* Pandas
* Matplotlib
* Google Colab
* Jupyter Notebook

# Key Findings 
The analysis identifies teh products and regions with the highest sales and profit and presents the results through basic visualizations.
